# 全站按钮样式统一修改报告

> 修改日期：2026-09-05。分支：`Xu_report`。目标：全站 17 个文件、109 个 `el-button` 统一为 Device Template / Device Deployment 界面的按钮规范（accent 半透明底、9px 圆角、无边框、10px 字号、20px 高、悬停上浮），图标统一为 `:icon` 属性写法。

---

## 1. 背景与问题

统一前，同一套按钮样式以 scoped 形式散落在 **6 个文件**里各维护一份（SystemDeploymentView、ProductManagerView、AlarmEventView、EventExportDialog、DeviceAlarmConfigDialog、TemplateDiagramDialog），导致：

- 三个 Alarms 界面（Alarm History / Alarm Config / Alarm Table）的按钮还是 Element Plus 原生样式，与 System 界面观感割裂；
- `NavNodeDialog`、`AlarmRuleEditModal`、`AlarmConfigView` 弹窗虽然写了 `btn-*` 类或用了 `type`，但因 append-to-body / 无样式定义，实际未被统一样式覆盖；
- 图标写法混杂：部分用 `:icon` 属性，部分用 `<el-icon>` 子元素嵌套；
- "Back" 返回按钮在三个页面有三种形态（私有 `.back-btn`、默认按钮、link 文字）。

## 2. 方案

**样式单点化**：将按钮样式提升到 `styles/global.scss` 全局定义一次（唯一权威来源），删除全部 6 份 scoped 私有副本。全局按 **type 属性自动配色**，绝大多数按钮模板零改动即被统一：

| 按钮 type | 配色（非 link） |
|---|---|
| `primary` / `.btn-primary` | accent-green 半透明底（16%，悬停 28%） |
| `default` / `info` / `.btn-secondary` | accent-blue 半透明底 |
| `success` | accent-green 半透明底（语义兼容，无独立色） |
| `danger` / `.btn-danger` | accent-red 半透明底 |
| `link` 文字按钮 | 透明底 + Element Plus 原生链接色（与参照页行内操作一致） |

例外规则：

- `.is-circle` 圆形图标按钮**整体排除**在全局样式外——FUXA 面板的两个悬浮圆钮是"透明底 + 描边 + 32px"的有意设计，统一几何会破坏它们；
- `.is-link` 保持透明底、自适应高度；
- `.is-disabled` 补 45% 透明度 + not-allowed 光标——因为 `!important` 配色会覆盖 Element Plus 默认的禁用变灰，需保证禁用态可辨识。

**图标统一**：所有按钮图标一律用 `:icon` 属性传入，清除 `<el-icon>` 子元素嵌套写法（共清理 7 处）。

## 6. 遗留说明

1. 3 个圆形图标按钮按设计保留原样，未纳入统一几何；
2. `success` 类型的按钮（如有新增）会自动映射为绿色，与 primary 同色调；
3. 后续新页面按钮**无需再复制样式**：直接用 `type` 属性（primary/danger）或 `btn-primary`/`btn-secondary`/`btn-danger` 类即可获得统一外观；图标一律 `:icon` 属性写法。
