# 右上角管理员姓名展示设计

## 目标

在主界面右上角展示当前登录管理员的姓名，仅提供信息展示，不承载任何账户操作。

## 用户体验范围

- 在 `TopNavbar` 右侧现有搜索图标旁显示一段普通文本。
- 优先显示当前用户的 `realName`。
- 当 `realName` 为空时，回退显示当前用户的 `username`。
- 姓名文本不提供点击、下拉、修改密码、退出登录或其他账户交互。
- 保留现有告警数量、搜索图标和顶部导航行为不变。

## 实现方案

复用现有 `auth` store 中的 `currentUser`，在 `TopNavbar.vue` 内增加一个只读的 `displayName` 计算值，并在模板中渲染普通 `span`。不新增后端接口，也不在顶部导航中重复请求用户信息。

路由守卫会在进入受保护页面时通过现有 `loadCurrentUser()` 补齐用户信息；登录成功时 `authStore.login()` 已经将登录响应中的用户信息写入 `currentUser`。因此顶部导航只需要订阅现有状态即可。

姓名样式沿用顶部导航的次级文本风格，保持单行显示，不设置鼠标指针或交互态样式。

## 影响范围

- `frontend/src/components/TopNavbar.vue`：增加姓名读取和展示，保持账户操作缺失。
- `frontend/tests/TopNavbar.system-account.test.mjs`：调整回归断言，确认姓名展示和取值回退存在，同时确认账户交互仍不存在。

不修改后端接口、认证流程、路由权限、`BottomToolbar` 中现有的 System 操作或密码修改逻辑。

## 验收标准

1. 登录后，右上角显示 `realName`；当其为空时显示 `username`。
2. 姓名区域是普通文本，不包含下拉菜单、点击处理器或账户操作入口。
3. 告警徽标、搜索图标和顶部导航的既有行为不受影响。
4. 前端回归测试通过。
5. 前端生产构建通过。
