# 本地图谱实验环境

本方案使用独立 Docker 项目 n4-lab。远程只作为一次性只读备份源。
不部署 TDengine，不开启 Flink、Kafka 采集或 FUXA。构图工具只读取冻结的本地备份。

## 服务
| 服务 | 版本 | 本地访问 |
|---|---|---|
| MySQL | 8.4.5 | 127.0.0.1:23306，数据库 n4_monitor |
| Redis | 7.4.10 | 127.0.0.1:16379 |
| Neo4j | 5.26.29 | Browser http://127.0.0.1:17474，Bolt 127.0.0.1:17687 |

独立随机密码只在根目录 .env.local 中。所有端口只绑定回环地址，使用独立命名卷。
Windows 保留了包含 13306 的端口范围，MySQL 改用实测可用的 23306。

## 初始化与启动
在根目录依次执行：

    python -m pip install -r scripts/local_lab/requirements.txt
    python scripts/local_lab/init_env.py
    docker compose --env-file .env.local -f compose.local.yaml up -d --wait

初始化工具不替换已有凭据。普通停止、重启保留卷；删除卷会删除实验数据。

## 备份与恢复
首次迁移执行：

    python scripts/local_lab/sync_data.py

默认来源为原 .env，可通过 --source-env 指定其他来源文件。
目标只能是 .env.local 中的回环地址、专用端口和 n4_monitor 数据库。
目标必须为空，避免覆盖已有实验结果。原 .env 不被修改。
.local-lab/backup-* 保存 SQL、JSON、表结构、数量、摘要和迁移报告。
MySQL 在单一只读一致性事务内导出，恢复后比较每表数量和内容摘要。
Redis 复制 alarm:* 业务哈希或字符串，保留剩余 TTL 并校验值，不复制持久化 Stream 任务或消费组。
Redis 逐键读取，不宣称与 MySQL 构成跨库原子快照。相同指恢复时的快照，之后本地独立变化。

## 图谱
执行：

    python scripts/local_lab/build_graph.py
    python scripts/local_lab/query_graph.py --device-id 43
    python scripts/local_lab/verify_lab.py
    python -m unittest discover -s scripts/local_lab -p "test_*.py"

节点包含部署节点、设备、设备模板、点位、点位模板、策略和触发条件。
数值规则保留高限大于等于、低限小于等于以及优先级，枚举行按策略名称分组。
未挂载设备保留，不虚构部署关系，也不从部署层级推断供电或通信依赖。
节点记录来源表和主键，不导入责任人、手机号等无关属性。
每次导入创建独立快照，全部节点属性和关系三元组核对通过后原子激活。
旧快照保留供复现，失败快照不替换当前版本。业务查询必须限定当前或指定快照。
Browser 中可用下述 Cypher 查看示例设备：

    MATCH (s:N4Snapshot {current:true,status:'verified'})
    MATCH path=(d:Device {snapshot:s.id})-[:HAS_POINT]->(p:Point)-[:USES_POLICY]->(r:AlarmPolicy)
    WHERE d.deviceDeployId=43
    RETURN path LIMIT 50

图谱可通过 Neo4j 和脚本查询，尚未接入 Ask Data 自动路由和回答生成。

## 前后端
执行：

    .\start-n4-monitor.bat

存在 .env.local 时，Spring Boot 最后导入该文件，IDE 启动也默认使用本地配置；启动脚本同时将它加载为子进程环境。
脚本会结束占用配置后端端口及 5173 的已有进程。
TDengine 关闭时不创建持久化消费者，历史读取返回未启用错误，问数不提供历史数据集。
Redis 是备份状态，不代表实时现场数据。历史查询、真实采集、FUXA 画面暂不启用。
数据库中复制的 MQTT 地址仍是来源属性；当前没有启动 FUXA/EMQX 使用它们。
未来启用采集前必须另行核对并本地化项目内部 MQTT 地址。

## 范围与隐私
第一版用于设备关系、点位定位和规则解释；历史证据融合待补充 TDengine。
没有导入真实供电拓扑、维修结论或根因标签，不把图查询称为根因诊断。
.env、.env.local、.local-lab/ 被 Git 忽略。备份含业务和账号数据，作为私有材料保管。
代码和文档不含真实凭据。仅本地提交，不推送。
