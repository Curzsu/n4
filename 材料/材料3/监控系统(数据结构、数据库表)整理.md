### 2.3 `alarm:latest`

暂存每个点位的最新数据。

| **项目** | **说明**                         |
| -------- | -------------------------------- |
| 类型     | Hash                             |
| key      | `alarm:latest`                   |
| field    | 点位路径 `path`                  |
| value    | `PointAlarmState` 的 JSON 字符串 |

JSON 字段结构：

| **字段名**  | **类型**      | **说明**                                  |
| ----------- | ------------- | ----------------------------------------- |
| name        | string        | 点位名                                    |
| displayName | string        | 显示名                                    |
| path        | string        | 点位完整路径                              |
| value       | string        | 点位值                                    |
| type        | string        | 点位类型                                  |
| unit        | string        | 单位                                      |
| max         | string        | 最大值                                    |
| min         | string        | 最小值                                    |
| ip          | string        | 设备 IP                                   |
| port        | string        | 端口                                      |
| other       | string        | 其他扩展信息                              |
| timestamp   | number        | 数据时间戳                                |
| level       | string / null | 报警等级                                  |
| severity    | string / null | 报警严重级别                              |
| message     | string / null | 报警消息                                  |
| hysteresis  | string / null | 滞回值                                    |
| ackBy       | string / null | 确认人                                    |
| status      | string / null | 状态，常见值 `Unack` / `Ack`              |
| source      | string / null | 来源                                      |
| location    | string / null | 位置                                      |
| duration    | string / null | 持续时间                                  |
| stage       | string / null | 阶段，常见值 `start` / `continue` / `end` |

### 2.4 `alarm:active`

暂存每个点位最近一次的报警数据。报警恢复正常则删除。

| **项目** | **说明**                         |
| -------- | -------------------------------- |
| 类型     | Hash                             |
| key      | `alarm:active`                   |
| field    | 点位路径 `path`                  |
| value    | `PointAlarmState` 的 JSON 字符串 |

JSON 字段结构：与 `alarm:latest` 相同。

### 2.5 `alarm:notifications`

| channel  | `alarm:notifications`                  |
| 消息内容 | `PointAlarmState` JSON 或聚合通知 JSON |

### 2.6 `alarm:realtime`

| **项目** | **说明**               |

| channel  | `alarm:realtime`       |
| 消息内容 | `PointAlarmState` JSON |

说明：该通道用于实时报警记录到 TDengine。

### 2.7 `alarm:point:rule`

| **项目** | **说明** |
| -------- | -------- |
| 类型     | Hash     |
| key      | `alarm:point:rule` |
| field    | 点位路径 `n4_address`（= Kafka 消息的 `path`） |
| value    | `alarm_code` 字符串（关联 alarm 表的 `alarm_name`，如 `Communication_Status_01`） |

说明：点位路径到报警规则的映射表。Flink 报警作业每条消息据此查到该点位对应的 `alarm_code`，再从 `alarm:rules:numeric`/`alarm:rules:enum` 取规则评估。`alarm_code` 为空的点位不写入此 hash，Flink 查不到即判定无规则、跳过报警判断。由后端 `AlarmRuleSyncService.syncPointRuleMapToRedis()` 全量同步（启动 + `/api/alarm-rules/reload`）。
